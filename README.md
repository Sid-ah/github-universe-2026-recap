# GitHub Universe 2026: announcements recap

An unofficial, single-page recap of the GitHub Universe 2026 announcements (keynote: October 28, 2026),
with short screen recordings of the new features running against a sandbox repository.

**Live site:** https://sid-ah.github.io/github-universe-2026-recap/

- Static HTML and CSS, no build step. Open `index.html` locally or serve the folder.
- Recordings (`media/*.mp4`) were made with [VHS](https://github.com/charmbracelet/vhs) against a private sandbox
  with intentionally buggy sample code.
- Typeface: [Mona Sans](https://github.com/github/mona-sans) (SIL Open Font License, `fonts/OFL.txt`).

Sources: [keynote recap](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/),
[Universe announcements](https://github.com/events/universe/recap), [GitHub Changelog](https://github.blog/changelog/).
