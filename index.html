02 · GitHub Copilot

Agent-first, multi-model, everywhere you work

Developers set direction and stay accountable. Agents implement and verify. Here's what's new.

Copilot Fusion

Choose the effort. Copilot picks the models.

Fusion is a runtime router and orchestrator. It reads what a task needs (reasoning, code generation, debugging, tool use) and picks how to run it.

StandardEveryday work, one model per task
HighComplex bugs, multi-file changes
MaxDeepest reasoning, still token-aware
  • Single: one model completes the task.
  • Cascade: an efficient model drafts; a judge accepts or escalates.
  • Critique: parallel critiques are aggregated, then the draft is revised.

Fusion Max scored within 2 points of Opus 5.5 Max on the Artificial Analysis Coding Agent Index, at half the cost and 40% less time per task.

GitHub Copilot appPROJECTS IN PUBLIC PREVIEW

From issue to merge, in one app

An agent-first surface for the whole job: specs, design discussions, telemetry analysis, and code.

  • Copilot projects: give Copilot a goal. It runs parallel, managed sessions across one or more repositories and checks in when it needs you.
  • Session continuity: start a cloud session from your phone at standup, steer it from VS Code, check on it from github.com. The agent keeps working in the cloud.
  • Connected context: pull in Slack threads, Figma designs, and meeting notes.
  • Image generation in chat, and computer use (preview, macOS and Windows) for desktop apps with no API, with your approval first.

AutomationsAGENTIC WORKFLOWS GA

Automations that learn from their outcomes

Copilot automations run Copilot cloud agent on a schedule, on repository events (issue created, PR opened or synchronized), or from the API. You choose exactly which GitHub and MCP tools each one can use, whether it's personal or shared, and an AI credit cap. Automation groups share context and propose improvements for you to approve.

GitHub Agentic Workflows is now generally available: write automation in Markdown, compile it to GitHub Actions. Agents are read-only by default, sandboxed behind the Agent Workflow Firewall, and every proposed change goes through safe outputs and a threat detection job.

Copilot code reviewMAX IN PREVIEWAPPROVALS GA

Max reviews, approvals, and Agent Merge

More code means more pull requests. Lite and Balanced keep everyday reviews fast. Max runs several independent review agents across models from different providers and reconciles their findings. It posted the highest F1 score on ReviewBench for high-severity issues.

  • Copilot approvals can count toward required reviews. Off by default, scoped by file path.
  • Agent Merge watches your pull request and fixes blockers such as failing Actions workflows and merge conflicts. Choose Watch and fix in the merge box.

03 · Platform

Reviewable changes, findable thinking

Collaboration primitives for humans and agents.

Stacked pull requestsPUBLIC PREVIEW

Break complex work into changes everyone can follow

Split a large change into focused, linked pull requests. Each one targets the layer below it, so reviewers see one focused diff at a time. Review each independently, then merge the whole stack in one click.

  • gh extension install github/gh-stack
  • gh stack init, gh stack add, gh stack submit
  • Teach your agents with gh skill install github/gh-stack
Media + issue artifacts--ATTACH GAARTIFACTS PREVIEW

Keep the screenshot and the plan with the work

GitHub CLI's repeatable --attach flag uploads images and videos inline into issues, pull requests, and comments.

Issue artifacts attach plans, research, links, and HTML visualizations to an issue, with version history, so your team and your agents share the same context. Copilot app sessions attach their artifacts automatically; gh issue artifact manages them from the terminal.

04 · Security

Secure by default, whoever wrote the code

Find and fix vulnerabilities in any language, stop secrets that patterns miss, and keep risky packages off your machines and runners.

Find and fixPUBLIC PREVIEW

AI Scan, AI-app scanning, and the security extension

  • AI Scan for repositories: scan a whole repository on demand, including languages CodeQL doesn't cover. Time-boxed for bounded cost. Findings land in code scanning next to CodeQL, without duplicates, and you can assign the backlog to Copilot.
  • Code scanning for AI applications: detects indirect prompt injection (XPIA), sensitive information disclosure, excessive agency, and more.
  • Security extension for the Copilot app: review what you and your agents just wrote next to your code scanning alerts, ask Copilot to explain and fix, then review each change.
  • Reachability analysis (JavaScript and TypeScript): shows whether your code actually calls the vulnerable function in a dependency, so you fix what's reachable first.
PREVIEW

AI push protection

A classifier built with Microsoft Applied Sciences blocks unstructured secrets, like passwords, at push time. In early results it more than doubled the pushes where push protection caught a secret.

PREVIEW

Package firewall

Blocks malicious, vulnerable, and brand-new npm versions before agents, runners, or IDEs install them, with cooldown periods and advisory checks.

GA

Public monitoring

Enterprises get alerted when their secrets are exposed publicly anywhere on GitHub.
